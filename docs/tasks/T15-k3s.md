**Status:** done · **Size:** M · **Depends on:** T10, T12 · **Blocks:** none

## Goal

The same stack as `make up`, running on Colima's built-in k3s from plain kustomize manifests,
with chat still unaffected when search or the replica goes down.

which reopened the "Compose only" scope decision. Compose stays the main path. Helm and minikube

## Gotchas

- kustomize only reads files in or below its own folder, so `kustomization.yaml` lives in `deploy/`
  to share the MySQL init scripts and monitoring configs with Compose. The command is
  `kubectl apply -k deploy`.
- Pods inherit the Mac's DNS search domains, and one of them resolved
  `host.docker.internal.medium.com` to a public address. Every Service has a ClusterIP, never
  headless, so names resolve before pods are ready, and `search` gets `host.docker.internal` from
  `hostAliases`.
- The kubeconfig also holds a remote context, `do-sgp1-sinbad-dev`. Never run `kubectl` without
  `--context colima`.
- The image tags stay `:dev`, so `make k8s-up` runs `rollout restart` on `api` and `search` to pick up
  a rebuild.
- `kubectl port-forward` ends when its pod restarts. `scripts/k8s-forward.sh` then stops the others
  and exits, so a dead forward is never silent.
